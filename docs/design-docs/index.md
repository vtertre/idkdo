# Design Docs

## Index

| Doc | Status | Use When |
| --- | --- | --- |
| `core-beliefs.md` | Accepted initial guidance | Making or reviewing code design decisions. |
| `code-organization.md` | Accepted initial guidance | Creating source files, organizing exported concepts, or adding tests. |

| `frontend-architecture.md` | Accepted initial guidance | Implementing Angular UI structure, frontend state, client repositories, PWA behavior, or browser-facing anti-spoil flows. |

## Design Doc Requirements

Each design doc should include:

- `Status`
- `Applies To`
- `Decision`
- `Details`
- `Verification`

When a decision is superseded, update or delete the doc; git history is the archive.
